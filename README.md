# MA-VAE

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT) [![DOI](https://img.shields.io/badge/DOI-10.5220%2F0012163100003595-blue.svg)](https://doi.org/10.5220/0012163100003595)

MA-VAE: Multi-head attention-based variational autoencoder approach for anomaly detection in multivariate time-series applied to automotive endurance powertrain testing

The paper corresponding to this repository, published as a regular paper in the 15th International Conference on Neural Computation Theory and Applications (NCTA 2023), can be found [here](https://www.scitepress.org/Link.aspx?doi=10.5220/0012163100003595).

Scripts can be found under the src folder. The data script outlines the pre-processing of the data. Each model has its own training script. The evaluation script outlines the steps taken to evaluate the models discussed.
requirements.txt contains all libraries used.
